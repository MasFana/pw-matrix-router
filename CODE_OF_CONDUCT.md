# Code of conduct

## Scope

This applies to issues, pull requests, discussions, and any other project space.

## Expected behavior

- Discuss the code and the design, not the person who wrote it.
- Give enough detail to reproduce a problem: version, distribution, PipeWire version, output rates.
- Accept that a maintainer may decline a change that conflicts with the device-ownership rules or the latency budget.

## Unacceptable behavior

- Harassment, insults, or discrimination of any kind.
- Publishing someone's private information without permission.
- Sustained disruption of issue threads after a maintainer has asked you to stop.
- Posting security details in a public issue instead of through [SECURITY.md](SECURITY.md).

## Enforcement

Report a problem to the maintainer through the contact options on the [maintainer's GitHub profile](https://github.com/MasFana) or use GitHub's **Report abuse** flow. Reports stay private.

The maintainer may edit or remove comments, close threads, or block accounts that break these rules. Decisions are explained to the people involved.

## Attribution

This policy is written for this project and follows the spirit of the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
